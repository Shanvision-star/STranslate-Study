# STranslate Study v0.1 公开发布范围

## 来源与目标

基于 STranslate v2.0.10（2a75118fe0fabc1135a619f4393eb3a8d936c5cd），保留 MIT 许可证与原作者声明。README 首页明确派生关系，说明新功能、与上游的关系和第三方组件许可。

发布面是通用源码、空白配置和 Windows x64 便携包。私人词库、模型凭据、个人对话 ID、运行日志、备份与机器路径不属于发布内容。

## 实现范围

1. 保留划词翻译、独立本地学习库、按选择汇总打印和隐私过滤。
2. 隐私拦截规则改为用户本机配置，公开源码不包含特定用户的机构规则。
3. 新增引导式学习助手配置。Codex CLI 与 Claude Code CLI 绑定明确会话；Codex 桌面端通过可用工具绑定私有对话；ChatGPT 缺少写入工具时提供手动导出，不宣称普通 API 可直接写入个人历史对话。
4. 外发默认关闭；可配置每两天练习。成功回执、未确认发送、失败与仅导出分别记录，不把送达当作掌握。
5. 提供标准 Windows 定时任务安装/卸载脚本，由用户明确运行；Codex 桌面端另提供绑定指引和自动化说明。
6. 公开包使用授权明确的 OCR 组件；不直接再分发授权边界未核实的原生 OCR 组件。许可证与固定版本/散列一并记录。
7. 打包运行时与必要的学习助手执行环境，不携带个人 Python 环境、翻译大模型权重或登录凭据；OCR 语言数据按独立许可提供。

## 接入边界

- CLI 使用现有登录与模型配置，不提取认证文件，不使用跳过权限或沙箱的选项。
- Claude Code 的语言练习调用禁用内置工具和 MCP 工具；不通过任意 shell 命令模板发送素材。
- 不使用自动选择“最近会话”代替用户绑定，不混入无关项目。
- 脱敏规则和候选难度估计都有范围限制。仅发送筛选后的词汇，不发送原段落和来源身份。
- 公司模式只调用用户配置的内网服务，本机保存，不连接个人 ChatGPT。

## 验证与发布门槛

- 原生保存/隐私/打印相关测试；新增配置、CLI 参数构造、失败回执、节流与手动导出测试。
- 便携包空白数据启动、离线 OCR 样例、学习助手引导与打印选择检查。
- 模拟 CLI 测试与真实会话送达分开标记；未安装的 CLI 不报告真实调用成功。
- 扫描待提交文件和发布包，检查个人标识、机器路径、凭据、词库和调试文件。
- 先形成可审阅提交，再创建公开 fork、推送独立默认分支、发布安装包并回读核验。

当前为执行计划，以上未完成项不代表已经实现或发布。
