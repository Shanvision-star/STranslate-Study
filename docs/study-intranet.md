# 公司内网使用

包里包含 .NET、Python、本地 OCR 和空白配置，**不包含翻译大模型**。OCR 只负责识别截图文字；把文字翻译为中文还需要公司批准的模型接口或离线翻译服务。

先由公司 IT 确认使用授权和依赖许可，特别是 [iNKORE.UI.WPF.Modern 的商业产品限制](../THIRD_PARTY_NOTICES.md)。公开源码和标注来源不意味着所有依赖均可无条件商业使用。

## 配置公司接口

1. 解压完整 ZIP 到可写目录。若电脑缺少 Visual C++ x64 运行库，请让 IT 准备官方离线安装器；不要依赖内网电脑下载依赖。
2. 设置 → 翻译服务 → 兼容接口，填写 IT 提供的 **Base URL、模型 ID、鉴权方式/密钥**。不要把密钥发到公开 issue。
3. 选择接口实际支持的 Chat Completions 或 Responses 模式。URL 按该插件界面填写；以公司网关的实际路径为准，避免重复添加 `/v1`。不关闭 TLS 验证。
4. 启用公司接口，保留 Microsoft 在线服务关闭。源语言明确选英语或西语，目标选简体中文；截图 OCR 选 Tesseract 本地。
5. 学习库发送开关保持关闭；不注册云端学习任务。自动更新和外部调用监听在初始配置中关闭，不需要打开。

VS Code 插件或桌面端能聊天，不足以确认公司对其他应用开放兼容接口。如果只有 Codex/Claude Code CLI 可调用公司模型，可以用于本工具的词汇练习集成；**当前翻译插件没有把 CLI 文本输出接成划词翻译服务**。这种情况仍需 IT 提供模型 API 或后续新增翻译适配器。

先用无业务信息的 `A coherent mechanism can strengthen a system.` 验证文本翻译，再用合成英文菜单截图验证 OCR。记录网关与模型配置、成功/错误信息即可；不要将原公司文档或密钥上传。公司真实接口尚未在本项目发布测试中验证。

词库、历史缓存、配置和日志都位于本机数据目录。即使学习库启用了部分脱敏，在线翻译请求仍会包含所选原文，因此选择哪个翻译服务必须符合公司数据政策。
