# Study v0.1.0 预览版

## 来源与变更

上游 STranslate v2.0.10，提交 `2a75118fe0fabc1135a619f4393eb3a8d936c5cd`；保留其 MIT LICENSE、版权及 Git 历史。

本次新增：本机 SQLite 学习库、公开来源脱敏、ASCII `index.html` 阅读页、按条目勾选汇总打印、Ctrl+Q 默认划词快捷键、用户绑定学习助手引导、隔日通用词汇练习与 Windows 当前用户任务。应用数据目录和单实例标识与原版分开。上游更新器关闭，避免用原版覆盖衍生功能。

公开包只带 Microsoft 在线翻译、OpenAI 兼容翻译和 Tesseract 本地 OCR，初始在线翻译均关闭。内置 Python 与 .NET 运行时，不包含个人数据、账号凭据或绑定会话。

## 验证范围

- Python 默认测试使用合成数据库与 CLI 回执替身，覆盖发送授权、目标绑定、两日间隔、模糊失败不重试、取消、隐私过滤及任务 XML。
- C# 回归覆盖学习库、取消/过期翻译保护、结果协调与选词事件。
- Tesseract 原生库与英/西/简中模型加载，合成英文菜单图片在英语和混合模式识别通过。
- 打包后检查嵌入式 Python 导入、空白配置、运行时、许可证及无个人数据库。

具体执行结果与校验和随 Release 说明发布。这里只描述检查范围，不将计划写为最终结果。

未验证：新安装 Windows 机器的实际点击体验、公司真实模型接口、当前公开版真实 Codex/Claude Code 模型会话、其他账号桌面端 ChatGPT 绑定、物理打印。此前个人定制版网页/PDF/截图使用反馈不直接等同于本次公开包验收。

版本为预览，未代码签名；使用自己的账号和模型配置可能产生额度消耗。报告问题时不要附完整词库或凭据。
